# Лоза — сайт ресторана

Демо-кейс коммерческого сайта ресторана средиземноморской и грузинской кухни: меню с поиском и фильтрами, корзина, оформление заказа (доставка/самовывоз), авторизация и личный кабинет с историей заказов.

## Стек

- **Next.js 16** (App Router, Turbopack) + TypeScript
- **Tailwind CSS v4** — дизайн-система на CSS-переменных
- **Supabase** — база данных, авторизация, RLS-политики (опционально, см. ниже)
- **Zod** — валидация формы оформления заказа
- **Sonner** — уведомления, **lucide-react** — иконки

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Supabase (опционально)

Без настройки Supabase сайт полностью работает в демо-режиме: меню — из локальных данных (`src/lib/seed.ts`), заказы гостя сохраняются в `localStorage` браузера. Это позволяет показать проект клиенту без какой-либо настройки.

Чтобы подключить реальную базу данных и авторизацию:

1. Создайте проект на [supabase.com](https://supabase.com).
2. В SQL Editor выполните по очереди `supabase/schema.sql` (таблицы + RLS) и `supabase/seed.sql` (тот же демо-каталог блюд).
3. Скопируйте `.env.local.example` в `.env.local` и заполните:
   ```
   NEXT_PUBLIC_SUPABASE_URL=...
   NEXT_PUBLIC_SUPABASE_ANON_KEY=...
   ```
4. Перезапустите `npm run dev` — меню, оформление заказа, регистрация/вход и личный кабинет начнут работать через Supabase.

## Структура

```
src/app/           страницы (главная, меню, корзина, заказ, кабинет, вход/регистрация)
src/components/    UI-примитивы, карточки блюд, шапка/подвал, форма авторизации
src/lib/           типы, данные меню, корзина (контекст), клиенты Supabase, оформление заказа
supabase/          SQL-схема и сид с демо-меню
```
